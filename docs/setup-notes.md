# دفترچهٔ راهنمای راه‌اندازی — Easy Prompt AI

این فایل خلاصهٔ کارهایی است که برای راه‌اندازی و نگهداری پروژه انجام شده. مثل یک
دفترچهٔ همیشه‌دم‌دست: هر وقت خواستی چیزی را عوض کنی یا یادت برود، از اینجا بخوان.

> برای جزئیات فنی و تصمیم‌ها، فایل `CLAUDE.md` در ریشهٔ پروژه را هم ببین.

---

## ۱) معماری کلی

- **`index.html`** — کل رابط کاربری (فرانت‌اند) در یک فایل. یک کلاینت سبک که فقط با API حرف می‌زند.
- **`worker/src/index.js`** — بک‌اند روی Cloudflare Worker. همهٔ کلیدها و منطق حساس اینجاست تا از مرورگر قابل‌خواندن نباشد.
- **`worker/src/engine.js`** — موتور تولید پرامپت (سؤال‌ها و ساخت خروجی).
- **دیتابیس D1** — کدهای فعال‌سازی، پرداخت‌ها، بازخوردها، تاریخچه و کش ترجمه.
- آدرس‌ها: سایت روی **easypromptai.net** و API روی **api.easypromptai.net**.

---

## ۲) چطور تغییرات لایو می‌شوند (خیلی مهم)

Cloudflare با گیت‌هاب وصل است (**Workers Builds**). یعنی:

> **هر بار که چیزی به شاخهٔ `main` مرج شود، Cloudflare خودکار دیپلوی می‌کند** (حدود ۱ تا ۲ دقیقه).

- مسیر کار: توسعه روی شاخهٔ فرعی → PR → **squash-merge به `main`** → دیپلوی خودکار.
- برای دیدن وضعیت: Cloudflare → Worker (اسمش `easy-prompt-ai`) → تب **Deployments**؛ آخرین بیلد باید سبز باشد.
- ⚠️ **ذخیرهٔ Secret در داشبورد، کدِ جدید را دیپلوی نمی‌کند** — فقط یک نسخهٔ جدید روی کدِ فعلی می‌سازد. کدِ جدید فقط با مرج به `main` می‌آید.
- بعد از هر تغییر، در مرورگر حتماً **Ctrl+F5** بزن تا کش پاک شود.

---

## ۳) کلیدها و متغیرها (Secrets)

جای تنظیم: **Cloudflare → Worker → Settings → Variables and secrets**.
هیچ‌وقت مقدار واقعی کلیدها را در گیت‌هاب/کد نگذار — فقط در Cloudflare.

| نام | نوع | توضیح |
|-----|-----|-------|
| `ADMIN_TOKEN` | Secret | ورود پنل مدیریت |
| `ANTHROPIC_API_KEY` | Secret | هوش مصنوعی (Claude) |
| `AI_MODEL` | Text | مدل مورد استفاده |
| `ALLOWED_ORIGIN` | Text | دامنه‌های مجاز (با کاما جدا) |
| `PAYPAL_CLIENT_ID` / `PAYPAL_SECRET` | Secret | پی‌پال |
| `PAYPAL_ENV` | Text | `live` |
| `PRICE_USDT` | Text | قیمت اشتراک |
| `USDT_TRC20_ADDRESS` و... | Text | آدرس‌های کیف پول |
| **`AZURE_TTS_KEY`** | Secret | کلید صدای Azure |
| **`AZURE_TTS_REGION`** | Text | `canadacentral` |

## ۴) صدا (Text-to-Speech) — چطور راه افتاد

**هدف:** برنامه در همهٔ زبان‌ها (فارسی/عربی/چینی و…) با صدای واقعی حرف بزند، روی هر دستگاهی.
مشکل صدای مرورگر این بود که فقط زبان‌هایی را می‌خواند که صدایشان روی دستگاه کاربر نصب باشد.

**راه‌حل:** یک سرویس صدا سمت سرور (`/api/tts`) که با **Azure Neural TTS** صدا می‌سازد و
فایل MP3 می‌دهد؛ روی هر دستگاهی پخش می‌شود.

### مراحلی که برای ساخت حساب Azure رفتیم
1. ثبت‌نام حساب رایگان Azure از `https://azure.microsoft.com/free` (تأیید کارت لازم بود؛ از سطح رایگان پولی کم نمی‌شود).
   - اگر خطای «tenant / AADSTS50020» دیدی، یعنی هنوز اشتراک نساخته‌ای؛ باید اول ثبت‌نام رایگان را کامل کنی، نه رفتن مستقیم به پرتال.
2. در پرتال: **Create a resource → Speech Services → Create**.
3. تنظیمات: Resource group = `easypromptai`، Region = **Canada Central**، Name = `easypromptai-tts`، **Pricing tier = Free F0** (رایگان، ۵۰۰٬۰۰۰ کاراکتر در ماه).
4. بعد از ساخت: **Keys and Endpoint** → `KEY 1` و Region را برداشتیم.
5. در Cloudflare گذاشتیم: `AZURE_TTS_KEY` (Secret) و `AZURE_TTS_REGION=canadacentral` (Text).

### تصمیم‌های صدا
- **هر زبان صدای مردانهٔ بومیِ خودش** را دارد (نگاشت `TTS_VOICE` در `worker/src/index.js`).
- زیر و بمِ صدا **دستکاری نمی‌شود** (فقط یک کندیِ خیلی جزئی `rate='-4%'`). دستکاری pitch باعث بدتلفظی فارسی می‌شد — دیگر اضافه نکن.
- ایدهٔ «یک صدای واحد برای همهٔ زبان‌ها» (صدای Andrew) امتحان شد و **رد شد**: فقط چند زبان را درست می‌خواند و برای فارسی به صدای پیش‌فرضِ خانم سوییچ می‌کرد.
- حالت شنیداری **به‌صورت پیش‌فرض روشن** است.

### کارِ باز (اگر بعداً خواستی)
صدای مردانهٔ فارسیِ Azure (`Farid`) متوسط است. برای فارسیِ طبیعی‌تر می‌شود **فقط برای فارسی**
از Google Chirp3-HD یا ElevenLabs استفاده کرد و بقیهٔ زبان‌ها روی Azure بمانند (از طریق
override زبانی در `TTS_VOICE`).

## ۵) باگ‌هایی که در همین مسیر درست شد
- **همگام‌سازی منوی زبان:** انتخاب زبان در صفحهٔ ورود، حالا ذخیره می‌شود و منوی زبانِ صفحهٔ اصلی را هم هماهنگ می‌کند.

## ۶) کارهای روزمره (چیت‌شیت)

- **تست سلامت کد قبل از push:** `node --check worker/src/index.js`
- **دیدن دیپلوی:** Cloudflare → Worker → Deployments (آخرین بیلد سبز؟)
- **بعد از هر تغییرِ لایو:** مرورگر → Ctrl+F5
- **تغییر پنل مدیریت / کلیدها:** فقط در Cloudflare → Variables and secrets
- **حافظهٔ پروژه برای جلسات بعد:** فایل `CLAUDE.md` (خودکار خوانده می‌شود)
