# مترجم آفلاین انگلیسی → فارسی

یک PWA (اپ نصب‌شدنی روی صفحهٔ خانه) که متن انگلیسی را روی خود گوشی به فارسی
ترجمه می‌کند. بعد از دانلود مدل (بار اول، حدود ۷۵ مگابایت)، **کاملاً آفلاین**
کار می‌کند — هیچ متنی از گوشی خارج نمی‌شود.

## ورودی‌های پشتیبانی‌شده

- **تایپ / paste** — متن انگلیسی را می‌چسبانی، دکمهٔ «ترجمه» می‌زنی.
- **کلیپ‌بورد** — دکمهٔ 📋 محتوای کلیپ‌بورد را می‌آورد (iOS اجازهٔ پایش خودکار
  در پس‌زمینه را نمی‌دهد؛ باید تپ کنی).
- **دوربین / OCR** — 📷 عکس متن انگلیسی می‌گیری، Tesseract.js متن را استخراج
  می‌کند، بعد ترجمه.
- **صدا / گفتار** — 🎤 با میکروفون به انگلیسی حرف می‌زنی، به متن تبدیل می‌شود.
  روی iOS Safari این قابلیت معمولاً به اینترنت نیاز دارد؛ آفلاین‌شدن آن نیاز
  به مدل Whisper دارد که فعلاً اضافه نشده.

## نصب روی آیفون

1. اپ را روی یک هاست HTTPS مستقر کن (پیشنهاد‌ها پایین).
2. در Safari آدرس اپ را باز کن.
3. دکمهٔ Share (مربع با فلش) → **Add to Home Screen**.
4. آیکون روی صفحهٔ خانه می‌آید؛ باز کردنش اپ را بدون نوار Safari اجرا می‌کند.
5. بار اول، در اپ روی «دانلود مدل برای استفادهٔ آفلاین» بزن (یا فقط یک ترجمه
   بزن؛ خودکار دانلود می‌شود). حدود ۷۵ مگابایت.
6. بعد از این، بدون اینترنت هم کار می‌کند.

## استقرار (Deploy)

اپ فقط فایل‌های استاتیک است. سه گزینه:

### Cloudflare Pages (پیشنهاد شده — چون از قبل روی CF هستی)

1. در داشبورد Cloudflare → Workers & Pages → Create → Pages.
2. **Connect to Git** → همین ریپو.
3. Build settings:
   - Build command: (خالی)
   - Build output directory: `offline-translator`
4. یک زیر‌دامنه رایگان `*.pages.dev` می‌گیری. برای دامنه دلخواه (مثلاً
   `translate.easypromptai.net`) در تب Custom domains اضافه کن.

### GitHub Pages

`_config.yml` ریشهٔ ریپو الان مربوط به Easy Prompt AI است. برای اینکه این پوشه
جدا سرو شود، ساده‌ترین کار این است که یک ریپوی جدید بسازی و فقط این پوشه را
داخلش بریزی، سپس در Settings → Pages فعالش کنی.

### نصب سریع محلی برای تست روی گوشی هم‌شبکه

روی لپ‌تاپ:

```bash
cd offline-translator
npx http-server -p 8080 --ssl  # یا از سرور HTTPS دیگری استفاده کن
```

روی آیفون Safari آدرس `https://<ip-لپ‌تاپ>:8080` را باز کن. توجه: PWA برای
Service Worker و Add-to-Home-Screen به HTTPS نیاز دارد؛ HTTP فقط روی
`localhost` کار می‌کند.

## مدل ترجمه

اپ دو مدل کاندیدا دارد و اولی که در دسترس باشد استفاده می‌شود:

| مدل | حجم (int8) | کیفیت | زبان‌ها |
|---|---|---|---|
| `Xenova/opus-mt-en-fa` | ~۷۵ MB | خوب برای متن روزمره | فقط en→fa |
| `Xenova/nllb-200-distilled-600M` (پشتیبان) | ~۱۵۰ MB | بهتر برای متن رسمی، کندتر | چند‌زبانه |

هر دو در transformers.js اجرا می‌شوند (ONNX روی WebAssembly، در صورت پشتیبانی
دستگاه WebGPU). مدل بار اول از HuggingFace CDN دانلود می‌شود و در Cache Storage
مرورگر می‌ماند.

اگر خواستی مدل را عوض کنی، آرایهٔ `MODEL_CANDIDATES` بالای `app.js` را ویرایش
کن.

## محدودیت‌های شناخته‌شده روی iOS

- **پایش خودکار کلیپ‌بورد** ممکن نیست (محدودیت اپل). دکمهٔ paste دستی است.
- **صدا** برای آفلاین‌شدن نیاز به Whisper WASM دارد (~۴۰MB اضافه). فعلاً از
  Web Speech API استفاده می‌شود که روی iOS آنلاین است.
- **حجم Cache** روی iOS برای PWA‌ها محدود است (تقریباً ۵۰ مگابایت برای
  IndexedDB/localStorage قدیمی، ولی Cache Storage اجازه می‌دهد چند صد مگابایت
  ذخیره شود). مدل ۷۵ مگابایتی جا می‌شود.
- **حذف اتوماتیک کش** اگر اپ چند هفته باز نشود ممکن است اتفاق بیفتد.
  ری‌دانلود در بازگشت خودکار انجام می‌شود.

## توسعه

فایل‌ها همه استاتیک هستند. هیچ build step ندارد.

```bash
# چک نحوی
node --check app.js
node --check sw.js

# اجرای محلی
npx http-server -p 8080 -c-1
```

## معماری

- `index.html` — ساختار UI (RTL فارسی، متا‌های PWA برای iOS).
- `styles.css` — تم تاریک، طرح واکنش‌گرا برای گوشی.
- `app.js` — منطق ترجمه، OCR، صدا، رجیستر سرویس‌ورکر.
- `sw.js` — کش شل + کش زمان‌اجرا برای CDN و مدل.
- `manifest.webmanifest` — متاداده PWA.
- `icons/` — آیکون‌های اپ.
