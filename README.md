محیط کاملاً گرافیکی با طراحی سه‌بعدی و مینیمال، بدون نیاز به سرور یا اینترنت (موتور آفلاین داخل مرورگر).

## 🚀 فاز بعد — فروش واقعی اکانت (نقشهٔ راه)

نسخهٔ فعلی برای **نمایش و استفادهٔ محلی** است؛ کدها در مرورگر (`localStorage`) ذخیره می‌شوند و اعتبارسنجی سمت کاربر انجام می‌شود. برای فروش واقعی و امن، این مراحل لازم است:

1. **بک‌اند + دیتابیس**: انتقال ساخت/اعتبارسنجی کدها به سرور (مثلاً Node + PostgreSQL) تا کدها قابل جعل نباشند و از چند دستگاه قابل کنترل باشند.
2. **حساب کاربری و ورود**: ثبت‌نام با ایمیل/شماره، مدیریت اشتراک و تاریخ انقضا در سرور.
3. **درگاه پرداخت**: اتصال به زرین‌پال/استرایپ برای خرید خودکار اشتراک بدون واسطهٔ کد دستی.
4. **اتصال به هوش مصنوعی واقعی**: افزودن لایهٔ API (Claude / GPT / Gemini) تا سؤال‌ها و پرامپت نهایی توسط مدل واقعی بهینه شوند — ساختار کد فعلی برای این کار آماده است (تابع `buildPrompt` جای اتصال است).
5. **پنل ادمین تحت وب**: گزارش فروش، مدیریت کاربران و تمدید اشتراک.

معماری فعلی به‌گونه‌ای نوشته شده که این ارتقاء بدون بازنویسی کامل ممکن باشد.
